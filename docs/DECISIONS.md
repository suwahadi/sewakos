> di-push, atau perilaku uang (SPEC-GO.md §0.5). Keputusan yang lebih besar tetap lewat AGENT.md §3
> (berhenti dan tanyakan pemilik).

| 2026-11-10 | `money.WIB` memakai `time.FixedZone` (offset tetap +7), bukan `time.LoadLocation("Asia/Jakarta")` | Indonesia tidak pernah menerapkan DST, jadi offset tetap sudah 100% benar, dan tidak bergantung pada paket `tzdata` yang mungkin tidak terpasang di image runtime minimal (`debian-slim`). |

Tidak memengaruhi kode yang dikirim ke pengguna. Tinjau ulang saat `eslint-config-next` merilis versi stabil yang memperbaikinya. |
| 2026-11-10 | `POST /api/auth/logout` (BFF) menghapus cookie sesi lokal meski panggilan `POST /auth/logout` ke backend gagal | Cookie di browser adalah satu-satunya salinan token di sisi klien; menahannya karena panggilan revoke gagal (mis. jaringan) akan membuat pengguna yang sudah minta keluar tetap terlihat masuk di perangkat itu. Diuji end-to-end terhadap backend asli: login mengisi cookie httpOnly (token tidak pernah terkirim ke body yang dibaca JS), logout memakainya sebagai Bearer lalu menghapusnya. |
| 2026-11-10 | `app/globals.css` ditambah `--duration-fast`/`--duration-base`/`--duration-slow` (120ms/200ms/280ms) di `@theme` | DESIGN.md §3.9 menyebut token ini sebagai bagian dari sistem gerak bersama `ease-standard`/`ease-exit`, tapi snapshot CSS di §3.10 (yang dokumennya sendiri tandai sebagai isi wajib) hanya mendefinisikan dua token `ease-*`, bukan `duration-*`. Tanpa token ini, komponen butuh `duration-[120ms]` (nilai mentah) yang justru dilarang §0 aturan 1. Penambahan murni melengkapi token yang sudah dideskripsikan §3.9 dengan nilai yang sama persis, bukan memperkenalkan nilai baru. |
| 2026-11-10 | Dimensi spesifik-komponen (bukan warna/radius/bayangan/durasi) boleh pakai nilai arbitrary Tailwind (`size-[72px]`, `h-[52px]`, dll.) bila di luar skala spasi default Tailwind | DESIGN.md §0 aturan 1 melarang warna hex/durasi/bayangan mentah karena itu adalah sistem token bermakna (§3) yang menjaga konsistensi brand. Ukuran satu-kali yang disebutkan apa adanya di anatomi komponen (mis. Warna, radius, bayangan, dan durasi tetap wajib memakai kelas token §3. |
| 2026-11-10 | Token `--duration-*` dan `--z-*` di `@theme` dipakai lewat `duration-[var(--duration-fast)]` / `z-[var(--z-toast)]`, bukan kelas `duration-fast`/`z-toast` langsung | Diverifikasi empiris dengan build nyata (grep CSS hasil `next build`): Tailwind v4 menghasilkan kelas utilitas otomatis dari namespace `--color-*`, `--text-*`, `--radius-*`, `--shadow-*`, `--ease-*`, tapi **tidak** dari `--duration-*` maupun `--z-*` (kelasnya tidak pernah muncul di CSS terkompilasi, tanpa error). Berlaku untuk semua komponen berikutnya yang memakai token durasi atau z-index kustom. |
